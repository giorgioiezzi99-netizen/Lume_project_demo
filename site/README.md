# The Lume Studios Website

Static prototype website for The Lume Studios.

## Project Structure

```text
.
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── LUME.png
    ├── lume-showcase.mp4
    └── still-clean-210.png
```

## Run Locally

Open `index.html` directly in a browser.

No build step, package install, or server is required.

## Notes

- `style.css` contains the complete visual styling.
- `script.js` handles the nav scroll state and reveal animations.
- `assets/` contains only the media currently used by the page.
